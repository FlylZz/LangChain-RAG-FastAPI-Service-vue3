# 项目截图目录

请将以下截图放置在此目录中：

1. `aichat.png` - AI 聊天界面截图
2. `chat_manager.png` - 聊天管理界面截图
3. `user_service.png` - 用户服务界面截图

## 截图要求

- 分辨率建议：1920x1080 或更高
- 格式：PNG
- 文件大小：建议小于 500KB
- 内容：展示项目的主要功能和界面

## 如何添加截图

1. 运行项目并打开各个界面
2. 使用截图工具截取屏幕
3. 将截图保存到此目录
4. 确保文件名与上述列表一致

## 示例截图内容

### aichat.png
- 展示 AI 聊天界面
- 包含用户提问和 AI 回答
- 显示流式输出效果

### chat_manager.png
- 展示聊天管理界面
- 包含会话列表
- 显示搜索和管理功能

### user_service.png
- 展示用户服务界面
- 包含用户信息管理
- 显示头像、昵称等信息
